# GNDSF — gndsf.ge (v0.1 · Phase 0–1 foundation)

საქართველოს სპორტული ცეკვების ეროვნული ფედერაციის პლატფორმა.
Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · PostgreSQL · Prisma (engine-less `client` mode + pg driver adapter).

## გაშვება ლოკალურად / Run locally

```bash
# 1. ბაზა (Docker)
docker compose up -d

# 2. დამოკიდებულებები
npm install

# 3. სქემა + სატესტო მონაცემები
cp .env.example .env
npx prisma migrate dev --name init   # creates real migrations on your machine
npm run db:seed

# 4. dev სერვერი
npm run dev                          # http://localhost:3000
```

თუ `prisma migrate` თქვენს გარემოში ვერ მუშაობს, `prisma/init.sql` იგივე სქემას ქმნის პირდაპირ:
`psql "$DATABASE_URL" -f prisma/init.sql`

## რა არის უკვე შესრულებული

- **სქემა**: სპორტსმენი / წყვილი / კლუბი / შეჯიბრება / შედეგი / ქულა / რეიტინგი —
  სრული lifecycle-დაცვით. შედეგები ებმის უცვლელ Entry ჩანაწერებს; პარტნიორის
  გაყრა/შეცვლა და კლუბის ტრანსფერი ისტორიას ვერასდროს დაარღვევს.
  `Entry`-ზე XOR check constraint (სოლო ან წყვილი — ზუსტად ერთი).
- **ქულების მოდელი**: ქულა ინდივიდუალურ სპორტსმენს მიჰყვება (WDSF მოდელი),
  წყვილის შედეგი ორ ჩანაწერს წერს; 12-თვიანი მოქმედების ვადა (`validUntil`).
  *კონფიგურირებადია — დაადასტურეთ ფედერაციის რეგლამენტით.*
- **რეიტინგის ჯობი**: `RankingEntry` სრულად გადაითვლება (truncate + rebuild),
  იდემპოტენტურია; ასაკობრივი კატეგორია ითვლება დაბადების წლიდან, არასდროს ინახება.
- **საჯარო გვერდები**: მთავარი, სპორტსმენების ბაზა (ძებნა/ფილტრი), პროფილი
  (პარტნიორობის ისტორია + შეჯიბრებების ისტორია), წყვილის გვერდი, რეიტინგი
  (ფილტრები URL-ში), სიახლეები, კალენდარი, კლუბები, დოკუმენტები, კონტაქტი.
- **ბრენდი**: ლოგო, favicon-ები, PWA მანიფესტი (Add to Home Screen), მუქი
  პრემიუმ დიზაინი ლოგოს ღვინისფერზე (#8B1520) აგებული.
